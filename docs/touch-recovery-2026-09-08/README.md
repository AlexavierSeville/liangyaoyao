## 交互规则

- 从鼠标按下开始计时，随机选择 5000–10000 ms，持续按住才触发。
- 每次按住最多触发一次；播放完成回到待机，继续按住不会重复惩罚。
- 松开、pointercancel、拖拽超过 5 px、控制器销毁或新指针会话都会取消旧计时。
- 翅膀左右侧在按下时锁定。拖动跨侧进入拖拽，不改变已经选定的动作。
- 肚子普通点击仍播放已有 `touch_belly_tickled`，连续点击不再触发 dislike。
- 翅膀普通点击不触发不耐烦。等待新素材期间，长按前半段保持已有待机；肚子保留 400 ms 后播放一次已有怕痒动作。
- 摸头开始、循环、松开和原有 9–13 秒的反应计时规则保留。
- Registry 的 `user_click` 沿用项目已有的鼠标交互触发类别；持续时间与侧别由 `PetInteractionController` 控制。

## 素材处理与视觉限制

原 ZIP 保留不变，SHA-256 与逐帧来源见 [import-report.json](import-report.json)。使用 `scripts/import-touch-reaction-zips.py` 可重现导入：

1. 从包内按编号读取每侧 01–12 帧。
2. 对边缘连通的米白背景做泛洪抠图；封闭深色轮廓保护奶油色腹部与眼睛高光。
3. 使用 hatch-pet 的连通组件检查保留企鹅和较大手部组件，去除独立的小动作线及背景碎片。与角色相连的原图动作线保留。
4. 每组使用统一等比缩放，以首帧企鹅高度对齐待机 198 px，并对齐头部中线和脚底参考点。保留原图内部姿态、踢脚与手部位移，不做逐帧拉伸或重新绘制。
5. 输出 640×456 的无损 RGBA WebP，`@2x` 在 Pixi 中为 320×228 逻辑尺寸，锚点为 `(0.5, 220/228)`。

**体型缩小已修复：** 初次导入为了容纳手部而降低了整组缩放，导致三组中性企鹅高度约为 172、170、146 px。现在由企鹅高度决定缩放，画布从 220×228 扩展为 320×228，仅在两侧各增加 50 px 透明空间，完整保留手部。企鹅、待机与其他动作的显示比例不受画布扩展影响；Windows 默认宽度和 10%–120% 宽度限制同步更新。

触摸判定仍使用居中的原 220×228 区域。新增透明边距不触发身体部位动作，缩放后仍与企鹅的位置对应。源图自身的表情、身体宽窄、姿态变化，以及末帧回待机的视角变化保留，本次只修正统一尺寸和注册位置。
